# COMP41670-Software-Engineering-Individual-Project (Chess)
Individual project for COMP41670-Software Engineering.
## Deployment

To deploy this project run

```bash
# Using Maven
    mvn clean compile 

# compile manually
    javac -d target/classes src/main/java/com/example/game/Board.java
    java -cp target/classes com.example.game.Board$0
```
